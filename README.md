# EDUTECH

A fully responsive Education Consultancy Website with Admin Panel built using **HTML, CSS, JavaScript, PHP, and MySQL**.

This system allows students to submit admission inquiries and enables the consultancy team to manage and track student leads through a secure admin dashboard.

---

## 🚀 Project Overview

This project is developed for an education consultancy agency that helps students choose the right college based on:

- Preferred Course (BTech, MBA, MCA, Diploma, etc.)
- Budget Range
- Preferred Location
- Academic Background
- Hostel Requirement

The system consists of:

- 🌐 Public Website (Frontend)
- 🔐 Admin Panel (Backend)
- 🗄 MySQL Database

## 🔄 System Workflow

1. Student fills inquiry form.
2. Data is submitted to `submit_inquiry.php`.
3. Information is stored in MySQL database.
4. Admin logs into dashboard.
5. Admin can view all student inquiries in real-time.
